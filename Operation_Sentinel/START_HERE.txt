OPERATION SENTINEL - SIMPLE START GUIDE (KALI LINUX)
===================================================

These uploads are a MIDTERM, not Lab 5's Juice Shop exercises.
You DO NOT need Docker or OWASP Juice Shop for this midterm.
You DO need Python 3 and a connection to the Internet to install requirements.

STEP 1 - EXTRACT THE ZIP INTO KALI
----------------------------------
Copy the ZIP to Kali, unzip it, and open a terminal inside the
Operation_Sentinel folder. For example:

  unzip Operation_Sentinel_Project.zip
  cd Operation_Sentinel

If your unzip makes an extra folder, cd into the folder containing client.py.

STEP 2 - SET UP PYTHON ONCE
---------------------------
  sudo apt update
  sudo apt install python3-venv python3-pip -y
  python3 -m venv .venv
  source .venv/bin/activate
  python3 -m pip install -r requirements.txt

STEP 3 - CREATE YOUR OWN LOGIN
-------------------------------
  python3 setup_account.py

Choose a username and a NEW password of at least 12 characters.
Save the printed TOTP setup secret privately in your authenticator app.
DO NOT screenshot the secret or publish sentinel_account.json.

STEP 4 - OPEN THREE KALI TERMINALS IN THE SAME FOLDER
------------------------------------------------------
Terminal 1 (the professor's training website):
  source .venv/bin/activate
  python3 test_website.py

Terminal 2 (your Sentinel TCP server):
  source .venv/bin/activate
  python3 server.py

Terminal 3 (the client/menu):
  source .venv/bin/activate
  python3 client.py

Log in with your own username, password and current 6-digit TOTP.
Select 1 to scan the localhost TCP ports, 2 to check the HTTP website,
and 3 to request server-side PCAP analysis.

STEP 5 - DO THE MIDTERM TESTS
-----------------------------
In Kali, open another terminal in this folder. Run:
  source .venv/bin/activate
  python3 -m unittest -v test_sentinel.py 2>&1 | tee evidence/test_run.txt

Check for 'Ran 18 tests' and 'OK'. If not, fix errors and retest.
Capture screenshots of (a) the running server, (b) login/menu,
(c) port scan, (d) HTTP findings, (e) PCAP results, and
(f) the full 18-test output. Do not reveal passwords or OTPs.

STEP 6 - COMPLETE THE REPORT
-----------------------------
Open Midterm_Report_Draft.md and the sample PDF. The PDF is a REPORT DRAFT,
not a finished verified submission. Add your name, student number, actual
Kali test outcomes, and screenshots. Replace placeholders. Explain each
section in your own words and make sure you understand the Python scripts.

Rename the final PDF in the format requested by your professor:
  FSCT8561-Midterm-FirstName-LastName-StudentNumber.pdf

STEP 7 - SUBMIT
----------------
1) The finished PDF report.
2) A GitHub repository link containing code, requirements.txt, and README.md.

Do NOT upload sentinel_account.json, .venv, or sentinel_security.log.

REMEMBER: This is a LOCAL-ONLY classroom demo. Plain TCP does not encrypt
passwords, OTPs, or report data; TOTP is not a replacement for TLS.
